## 🎯 About the Project

**YallaBuy** is a modern Arabic e-commerce content platform specialized in **in-depth product reviews, comparisons, and buying guides** for electronics and gadgets available on Amazon.

The name combines **"Yalla"** (Arabic for "Let's go!") + **"Buy"** — encouraging users to make smart, informed purchases.

> 💡 **Mission:** Help Arabic-speaking users make confident buying decisions by providing honest reviews, side-by-side comparisons, and practical buying advice — all in one place.

### What makes YallaBuy special?
- Fully written and curated reviews (not auto-generated)
- Focus on real-world usefulness for Arabic users
- Lightweight, fast, and mobile-first experience
- Progressive Web App (PWA) with offline support
- Strong SEO foundation and structured data
